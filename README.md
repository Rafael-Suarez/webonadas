# Webonadas

Rafael's Minecraft server for friends. The modpack has everything the server runs, so you join with the same mods.

## Download the modpack

**[Download Webonadas.zip](https://github.com/Rafael-Suarez/webonadas/releases/latest/download/Webonadas.zip)** (about 290 MB)

That link always gives the newest version. When the server moves to a new one, download it again and import it the same way.

## How to join

1. Install the **CurseForge app**: <https://www.curseforge.com/download/app>. Pick Minecraft when it asks.
2. In CurseForge, go to **Minecraft**, then **Create Custom Profile** at the top right.
3. Click **Import**, then pick the **Webonadas.zip** you downloaded. Don't unzip it.
4. Wait while CurseForge downloads the mods. It's slow the first time.
5. Click **Play**. Minecraft opens.
6. Go to **Multiplayer**, then **Add Server**, and fill in:
   - Server Name: `Webonadas`
   - Server Address: `mc.rafael-suarez.com:25566`
7. Click **Done**, then join.

If it won't let you in, message Rafael with your Minecraft name.

## Updating

When there's a new version, Rafael will say so.

1. Download the zip again from the link above.
2. In CurseForge, import it the same way. You can delete the old profile first; your worlds are on the server, not in the profile.

## What's inside

The zip lists 123 mods by their CurseForge IDs; CurseForge downloads those itself. A few files are included directly, all of which may be shared: Emotecraft (GPL), YUNG's API (LGPL), VOSK speech models (Apache 2.0), and emotes (CC0). See CREDITS.txt in the zip.
